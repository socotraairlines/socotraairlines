نشر الموقع (سريع) / Quick publish

خيار GitHub (يوصي به):
1. أنشئ مستودعًا على GitHub باسمك المفضل.
2. ربط المستودع المحلي ثم دفع:

   cd /Users/hussaito/SocotraAirlinesSite
   git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git
   git branch -M main
   git push -u origin main

3. من إعدادات المستودع -> Pages -> اختر الفرع main، المسار root، ثم Save.

Netlify (بدون Git):
- ادخل: https://app.netlify.com/drop واسحب مجلد `SocotraAirlinesSite` لتحصل على رابط نشر تلقائي.
